# creapulse-skills-SEO-and-co

Librairie monorepo de **skills Claude Code** orientés marketing : SEO (cœur) + analytics,
content, social, UX, design, CRO, landing pages.

Skills curatés depuis GitHub, **vendorisés** avec un manifeste de provenance (`registry.yml`),
normalisés, puis maintenus via deux veilles (upstream + web).

📋 **Le plan complet est dans [ROADMAP.md](./ROADMAP.md).** C'est le fil conducteur du projet —
à ouvrir au début de chaque session de travail.

## État

Planification. Rien n'est encore construit. Voir la Phase 0 de la roadmap.

## Principe

Vendoring + manifeste : on copie l'utile, on trace l'origine (repo + commit SHA + licence),
on décide **par skill** s'il reste synchronisé avec l'upstream (`tracked`) ou s'il devient nôtre
(`forked-hard`). Les veilles **proposent**, on valide — jamais d'auto-merge.
